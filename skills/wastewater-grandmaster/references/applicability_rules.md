# 适用性规则

本文档规定雨水和污水计算中使用的单位、适用范围边界和算法切换规则。

## 1 单位制

### 1.1 雨水设计流量公式 (4.1.9)

暴雨强度公式用于计算雨水管渠设计流量：

```
q = 167A / (t + b)^c
```

| 参数 | 含义 | 单位 |
|------|------|------|
| q | 设计暴雨强度 | L/s·hm² |
| F | 汇水面积 | hm² |
| t | 降雨历时 | min |
| A, b, c | 地方暴雨参数 | 无量纲 |
| Q | 设计雨水流量 | L/s |
| ψ | 径流系数 | 无量纲 |

公式推导：`Q = ψ × q × F / 10000`（单位换算）

### 1.2 污水旱季设计流量 (4.1.13)

旱季设计流量包括综合生活污水量和工业废水量：

| 参数 | 含义 | 单位 |
|------|------|------|
| Q_d | 综合生活污水量 | L/s 或 m³/d |
| Q_m | 工业废水量 | m³/d |
| K_z | 总变化系数 | 无量纲 |

### 1.3 水力计算 (5.2.1 / 5.2.2)

排水管渠水力计算公式：

```
v = (1/n) × R^(2/3) × I^(1/2)
Q = v × A
```

| 参数 | 含义 | 单位 |
|------|------|------|
| Q | 设计流量 | m³/s |
| v | 流速 | m/s |
| n | 粗糙系数 | 无量纲 |
| R | 水力半径 | m |
| I | 水力坡降 | 无量纲 |
| D | 管径 | mm |

常用粗糙系数：
- 塑料管道：n = 0.009~0.011
- 钢筋混凝土管：n = 0.013~0.014

### 1.4 生物反应池容积 (7.6.10)

生物反应池容积计算两种方法：

**方法一：按污泥负荷计算**
```
V = Q × (S_o - S_e) / (1000 × L_s × X)
```

**方法二：按污泥龄计算**
```
V = Q × Y × θ_c × (S_o - S_e) / [1000 × X_v × (1 + K_d × θ_c)]
```

| 参数 | 含义 | 单位 |
|------|------|------|
| V | 生物反应池容积 | m³ |
| Q | 设计流量 | m³/d |
| S_o | 进水BOD₅浓度 | mg/L |
| S_e | 出水BOD₅浓度 | mg/L |
| L_s | 污泥负荷 | kgBOD₅/(kgMLSS·d) |
| X | 混合液悬浮固体浓度 | gMLSS/L |
| θ_c | 设计污泥龄 | d |
| Y | 污泥产率系数 | kgVSS/kgBOD₅ |
| K_d | 衰减系数 | d⁻¹ |

## 2 适用范围边界

### 2.1 暴雨强度公式适用条件

| 条件 | 限制值 | 说明 |
|------|--------|------|
| 汇水面积 F | ≤ 2 km² | 适用于推理公式 |
| 汇水面积 F | > 2 km² | 应采用数学模型 |
| 地面集水时间 t₁ | 5~15 min | 经验值 |
| 降雨历时 t | 5~120 min | 短历时降雨 |

**说明**：当汇水面积超过 2 km² 时，推理公式会产生较大误差，应采用数学模型法。

### 2.2 地面集水时间 t₁

根据地面坡度和覆盖情况确定：

| 地面情况 | t₁ (min) |
|----------|----------|
| 陡坡、密集建成区 | 5~8 |
| 平缓、住宅区 | 10~15 |
| 平坦、郊区 | 20~30 |

### 2.3 设计重现期区分

| 设施类型 | 重现期 | 说明 |
|----------|--------|------|
| 雨水管渠（中心城区） | 2~5 年 | 短历时强降雨 |
| 雨水管渠（非中心城区） | 2~3 年 | - |
| 内涝防治 | 10~50 年 | 长历时降雨 |
| 地下通道、下沉广场 | 10~50 年 | 最低洼处 |

### 2.4 污水管道设计流量

| 条件 | 适用公式 |
|------|----------|
| 旱季流量 | Q = Q_d + Q_m |
| 雨季流量 | Q_rain = Q_dry + Q_storm |
| 总变化系数 K_z | 查表 4.1.15 |

流量与 K_z 关系：
- Q ≥ 1000 L/s → K_z = 1.5
- Q = 200 L/s → K_z = 1.8
- Q = 40 L/s → K_z = 2.1
- Q = 5 L/s → K_z = 2.7

## 3 算法切换规则

### 3.1 雨水设计流量算法切换

**切换触发条件**：汇水面积 F > 2 km²

**切换前（推理公式法）**：
```
Q = ψ × q × F / 10000
```
适用：F ≤ 2 km²，汇流时间 t < 15 min

**切换后（数学模型法）**：
- 采用产流模型（如 Horton 模型、Green-Ampt 模型）
- 采用汇流模型（如单位线法、等流时线法）
- 采用管网水动力模型

**依据条款**：GB 50014-2021 第 4.1.7 条
> 当汇水面积超过 2 km² 时，雨水设计流量应采用数学模型进行确定。

### 3.2 污水变化系数算法

**总变化系数计算式**（按日流量）：

| 来源 | 公式 | 适用范围 |
|------|------|----------|
| 上海泵站拟合 | lg K = -0.1156 × lg Q + 0.5052 | 流量统计 |
| 美国加州 | K = 5.453 / P^0.0963 | 人口法 |
| Harmon | K = 1 + 14 / [4 + (P/1000)^0.5] | 人口法 |
| Rabbitt | K = 5 / (P/1000)^0.2 | 人口法 |

**最小值规定**：K_z 不应低于 1.5~2.7（根据流量规模）

### 3.3 生物反应池计算方法切换

**切换条件**：去除目标变化

| 处理目标 | 计算方法 | 适用公式 |
|----------|----------|----------|
| 去除碳源污染物为主 | 污泥负荷法 | 7.6.10-1 |
| 去除碳源污染物为主 | 污泥龄法 | 7.6.10-2 |
| 需同时脱氮除磷 | A²/O 法 | 7.6.19 |
| 仅需除磷 | A/O 法 | 7.6.18 |
| 仅需脱氮 | A/N 法 | 7.6.17 |

### 3.4 排水体制切换

| 条件 | 体制选择 |
|------|----------|
| 截流污染要求高 | 合流制 + 截流倍数 |
| 水资源短缺 | 分流制 + 雨水利用 |
| 环保要求严格 | 分流制 + 调蓄池 |

截流倍数参考值：
- 英国：5
- 德国：4
- 美国：1.5~5
