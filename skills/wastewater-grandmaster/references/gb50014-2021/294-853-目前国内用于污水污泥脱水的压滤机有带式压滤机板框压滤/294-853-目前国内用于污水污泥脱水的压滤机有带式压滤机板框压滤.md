# 8.5.3 目前，国内用于污水污泥脱水的压滤机有带式压滤机、板框压滤机、厢式压滤机和微孔挤压脱水机。

由于各种污泥的脱水性质不同，泥饼的产率和含水率变化较大，所以应根据试验资料或参照相似污泥的数据确定。

《日本指南》从脱水泥饼的处理和泥饼焚烧经济性考虑，规定泥饼含水率宜为 $75\%$ ；天津某污水厂消化污泥经压滤机脱水后，泥饼含水率为 $70\% \sim 80\%$ ，平均为 $75\%$ ；上海某污水厂混合污泥经压滤机脱水后，泥饼含水率为 $73.4\% \sim 75.9\%$ ；厦门某污水厂

混合污泥经石灰等药剂调理后，通过压滤机脱水，泥饼含水率为 $55\% \sim 60\%$ 。
