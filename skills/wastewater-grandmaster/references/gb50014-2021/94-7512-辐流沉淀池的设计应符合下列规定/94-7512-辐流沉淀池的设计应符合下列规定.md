# 7.5.12 辐流沉淀池的设计应符合下列规定：

1 水池直径(或正方形的一边)和有效水深之比宜为 $6 \sim 12$ ，水池直径不宜大于 $50 \mathrm{~m}$ 。  
2 宜采用机械排泥, 排泥机械旋转速度宜为 $1 \mathrm{r} / \mathrm{h} \sim 3 \mathrm{r} / \mathrm{h}$ , 刮泥板的外缘线速度不宜大于 $3 \mathrm{~m} / \mathrm{min}$ 。当水池直径 (或正方形的一边) 较小时也可采用多斗排泥。  
3 缓冲层高度, 非机械排泥时宜为 $0.5 \mathrm{~m}$ ; 机械排泥时, 应根据刮泥板高度确定, 且缓冲层上缘宜高出刮泥板 $0.3 \mathrm{~m}$ 。  
4 坡向泥斗的底坡不宜小于0.05。  
5 周边进水周边出水辐流沉淀池应保证进水渠的均匀配水。Ⅲ 斜管(板)沉淀池
